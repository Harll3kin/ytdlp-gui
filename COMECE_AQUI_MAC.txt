PASSO 1: Abra Terminal
  • Cmd + Space
  • Type "terminal"
  • Enter

PASSO 2: Vá para a pasta
  cd /path/to/ytdlp-gui

PASSO 3: PRIMEIRA VEZ (verificar requisitos):
  chmod +x *.sh && bash check_and_setup_mac.sh

  → O script vai perguntar se quer instalar o que falta
  → Você responde "y" (sim) ou "n" (não) pra cada coisa

PASSO 4: DEPOIS (compilar o instalador):
  bash build_installer_mac.sh

PRONTO! ✅
  • Você terá um arquivo: dist/ytdlp-gui-1.0.0.dmg
  • Esse é o INSTALADOR pronto!
