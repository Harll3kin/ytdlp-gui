====================================================================
  yt-dlp GUI - Instalação no Mac
====================================================================

Não precisa instalar Python, nem yt-dlp, nem ffmpeg, nem usar o
Terminal. Está tudo dentro do app.


1. BAIXAR
--------------------------------------------------------------------
   https://github.com/Harll3kin/ytdlp-gui/releases/latest

   Tem dois arquivos. Escolha conforme o seu Mac:

     Mac com chip M1/M2/M3/M4  ->  ...-macos-applesilicon.dmg
     Mac com chip Intel        ->  ...-macos-intel.dmg

   Na dúvida: menu Apple () > "Sobre este Mac". Se aparecer "Chip
   Apple M...", é applesilicon. Se aparecer "Processador Intel", é
   intel.


2. INSTALAR
--------------------------------------------------------------------
   - Abra o .dmg (duplo-clique)
   - Arraste "ytdlp-gui" para a pasta Applications


3. PRIMEIRA ABERTURA (passo importante)
--------------------------------------------------------------------
   O app não é notarizado pela Apple, então o macOS vai bloquear na
   primeira vez com uma mensagem tipo "não foi possível verificar o
   desenvolvedor". Isso é esperado.

   Para liberar:

     1. Tente abrir o app uma vez (vai aparecer o aviso; clique OK)
     2. Abra Ajustes do Sistema > Privacidade e Segurança
     3. Role até o fim - vai ter uma linha sobre o ytdlp-gui
     4. Clique em "Abrir Mesmo Assim" / "Open Anyway"

   Isso é só na primeira vez.


COMO USAR
--------------------------------------------------------------------
   - Cole o link do YouTube
   - Escolha MP3 (áudio) ou MP4 (vídeo)
   - Clique em Download

   MP4 baixa sempre em H.264, que é o codec que o Premiere Pro
   aceita. É o que resolve o erro "unsupported compression type
   av01".

   MP4 vai para:  ~/Movies/EDIT/ASSETS
   MP3 vai para a pasta que você escolher.

   O app atualiza o yt-dlp sozinho ao abrir. Isso evita o erro 403
   que aparece quando o YouTube muda alguma coisa.


PARA DESINSTALAR POR COMPLETO
--------------------------------------------------------------------
   1. Arraste o app de Applications para o Lixo
   2. Apague esta pasta:
        ~/Library/Application Support/ytdlp-gui

   É só isso - nada foi instalado no resto do sistema.


SE DER ALGUM ERRO
--------------------------------------------------------------------
   Tire print da mensagem e mande. O app foi compilado e testado
   automaticamente para Intel e Apple Silicon, mas o download em si
   não pôde ser testado de ponta a ponta num Mac real ainda.
