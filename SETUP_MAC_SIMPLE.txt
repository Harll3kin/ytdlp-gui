╚═══════════════════════════════════════════════════════════════╝

PASSO 1: Abra o Terminal (Cmd + Space, type "terminal")

PASSO 2: Vá para a pasta do projeto
  cd /path/to/ytdlp-gui

PASSO 3: Copie e cole no Terminal (um de cada vez):
  pip3 install -r requirements.txt
  bash build.sh

PASSO 4: Quando terminar, abra o app:
  open dist/ytdlp-gui.app

═══════════════════════════════════════════════════════════════

Pronto! O app vai estar rodando.

Se algo não funcionar, veja README_MAC.md para troubleshooting.
