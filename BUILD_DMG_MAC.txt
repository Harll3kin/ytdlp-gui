║    yt-dlp GUI - Criar Instalador DMG para Mac (Seu Chefe)    ║
╚═══════════════════════════════════════════════════════════════╝

SEU CHEFE RODA ISSO EM UM MAC:

═══════════════════════════════════════════════════════════════

1. Abra Terminal (Cmd + Space, type "terminal")

2. Navegue para a pasta do projeto:
   cd /path/to/ytdlp-gui

3. Copie e cole NO TERMINAL:

   pip3 install -r requirements.txt
   chmod +x build_installer_mac.sh
   bash build_installer_mac.sh

═══════════════════════════════════════════════════════════════

O resultado será um arquivo chamado:
  dist/ytdlp-gui-1.0.0.dmg

Esse arquivo é o INSTALADOR pronto pra distribuir!

═══════════════════════════════════════════════════════════════

PARA USAR O INSTALADOR (você ou qualquer pessoa):

1. Download do arquivo .dmg
2. Duplo-clique pra abrir
3. Arrasta "yt-dlp GUI" pra pasta Applications
4. Pronto! App instalado e pronto pra usar

═══════════════════════════════════════════════════════════════

TROUBLESHOOTING:

❌ "command not found: bash"
   → /bin/bash build_installer_mac.sh

❌ "Permission denied"
   → chmod +x build_installer_mac.sh

❌ "pip3 not found"
   → Instale Python 3 com: brew install python3

✅ Quando terminar, o arquivo .dmg estará em dist/
